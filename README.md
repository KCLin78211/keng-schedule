# 耕讀園排班與人資系統

這是一個第一版靜態 Web 原型，可直接用瀏覽器開啟 `index.html`。

## 已實作

- 月曆矩陣排班表，欄位對應日期，列對應員工與職稱。
- 月排班矩陣右側統計病假、事假、公假、出勤天數。
- 員工姓名下方顯示本月已排工時與未排工時。
- 資料維護包含特休管理，可設定年度額度、期限，並依排班格中的特休自動統計已用、剩餘天數與已用日期。
- 頁首可切換角色；員工可看人資儀表板中的自己資訊、特休使用與每日職務覆蓋，人資/管理員可看資料維護。
- 排班表可切換「全部員工」或單一員工檢視。
- 手機版可切換卡片清單或矩陣排班表，底部有固定功能切換列。
- 排班格可編輯多個班別、休、例假、休息日、特休、請假與備註。
- 點開有警示的排班格，可查看警示規則、原因與建議修正方式。
- 新增員工上班日期可在「資料維護 > 快速排班」選員工、日期、班別後套用。
- 人資儀表板顯示總工時、阻擋警示、加班風險、特休/請假數。
- 法遵檢核包含每日 8/12 小時、每週契約工時與 40 小時、連續出勤、一例一休、輪班 11 小時間隔、班中 30 分鐘休息、國定假日出勤提醒。
- 資料維護可新增、修改、刪除員工與班別。
- 支援 CSV 匯出與瀏覽器列印/PDF。

## 第一版限制

- 使用瀏覽器記憶體中的範例資料，重新整理後會回到預設資料。
- 不包含登入、後端資料庫、打卡機整合、薪資結算。
- 法遵結果是排班管理警示，不取代個案法律意見。
